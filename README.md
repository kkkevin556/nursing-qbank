# 护理刷题站（安卓 PWA）

一个无需构建工具、可部署到 GitHub Pages 的中文护理刷题 PWA。手机浏览器打开后可添加到主屏幕；首次联网加载后可离线使用。

## 当前功能
- 五类题库分类入口：护士资格考试、护理学、护理三基、护士规培、护理职称考试
- 随机/顺序练习、分类筛选、关键词搜索
- 即时判题、解析、错题本、收藏、学习统计
- JSON 题库导入/导出、学习记录导出
- Service Worker 离线缓存；进度与题库保存在当前浏览器本地

## 部署到 GitHub Pages
1. 在 GitHub 新建一个 **Public** 仓库，例如 `nursing-qbank`。
2. 将本项目内所有文件和文件夹上传到仓库根目录（不要只上传 ZIP）。
3. 进入仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
5. 等待 GitHub Pages 发布，访问 `https://你的GitHub用户名.github.io/nursing-qbank/`。
6. 安卓 Chrome 打开网址 → 右上角三点 → **安装应用** 或 **添加到主屏幕**。

## 题库 JSON 格式
```json
[
  {
    "id": "nurse-0001",
    "category": "护士资格考试",
    "question": "题干",
    "options": {"A": "选项A", "B": "选项B", "C": "选项C", "D": "选项D"},
    "answer": "A",
    "explanation": "答案解析",
    "source": "来源/年份/许可说明"
  }
]
```

支持的分类名称：`护士资格考试`、`护理学`、`护理三基`、`护士规培`、`护理职称考试`。题库可在应用的“题库管理”中导入。相同 `id` 会覆盖更新。
